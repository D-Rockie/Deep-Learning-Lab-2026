# Experiment 7 - Autoencoders, Convolutional, Denoising and Variational

Single notebook: `Experiment_7_Autoencoders.ipynb`

**Covers:** MNIST reconstruction with a fully connected autoencoder (latent 16),
a convolutional autoencoder, a denoising CAE (Gaussian and salt-and-pepper),
and a 2-D variational autoencoder with latent-space visualisation, sampling and
interpolation. Includes MSE/MAE/SSIM evaluation, a latent-dimension study and
eight additional exercises.

**Run (local):** `pip install -r requirements.txt`, then run all cells.
`WORK_DIR` falls back to the current directory.
